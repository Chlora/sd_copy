--DESCRIÇÃO--

Este projeto cria 2 ficheiros, que quando executados em terminais separados, simulam interações cliente-servidor em torno de uma lista de dados. A comunicação entre os dois processos é efetuada via protocol buffer. 
Cada servidor e cliente suportam apenas uma ligação.
